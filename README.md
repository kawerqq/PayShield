# PayShield — финальный комплект версии 1.0.0

## Что в комплекте
- `05_app.py` — исправленный CLI-прототип.
- `02_правила.md`, `03_data_dictionary.md`, `04_requirements.md` — единые правила, словарь данных и требования.
- `06_openapi.yaml` — целевой HTTP-контракт OpenAPI 3.0.3.
- `07_confirmation.md`, `08_gateway_emulator.md` — подтверждение и эмулятор.
- `test.md`, `tests/test_prototype.py` — тест-сценарии и автоматизированные проверки.
- `06_приложение.md`, `06_приложение.docx`, `06_приложение.pdf` — приложение к кейсу (12 страниц).
- `PayShield_техническая_документация.md`, `.docx`, `.pdf` — полная техническая документация (14 страниц).
- `01_данные/payments.csv`, `01_данные/recipients.csv` — исходные данные.
- `payments_out.csv` — переданный пользователем текущий журнал; не очищен и не перезаписан тестовыми данными.
- `payment_*.json` — примеры запросов.

## Запуск на macOS
Из каталога проекта:

```bash
python3 05_app.py payment_success.json
```

Примеры отказа, ошибки и таймаута:
```bash
python3 05_app.py payment_decline.json
python3 05_app.py payment_invalid.json
python3 05_app.py payment_timeout.json
```

Повтор с тем же ключом:
```bash
python3 05_app.py payment_replay.json
python3 05_app.py payment_replay.json
```

Файлы `payment_service.log` и `gateway.log` создаются автоматически рядом с `05_app.py`.

## Зафиксированный релиз

`1.0.0` — финальная базовая версия данного комплекта. Исполняемый CLI, правила, API-контракт, тесты и документация зафиксированы вместе.

## Важные границы реализации
1. Это CLI, не HTTP-сервер. `06_openapi.yaml` — целевой контракт, сетевые маршруты не реализованы.
2. В CLI `Idempotency-Key` передаётся в JSON как `idempotency_key`; в HTTP-контракте это заголовок.
3. `confirm_token`, SMS и biometric_stub описаны, но не реализованы в CLI.
4. `payments_out.csv` сохраняет текущие данные пользователя. При первом запуске код автоматически добавит колонку `response_json`, если встретит старую 12-колоночную схему.
5. Исходный `payments.csv` не изменяется.
6. Перед сдачей заполнить ФИО/часы/подписи команды, даты журнала ИИ и приложить скриншоты коммита и запусков T1-1/T1-3.

## Финальная фиксация версии

Версия 1.0.0 — согласованный и проверенный базовый комплект. Прототип и документация соответствуют друг другу в пределах описанных ограничений. HTTP-сервер и двухэтапное подтверждение не входят в реализованную CLI-часть.
